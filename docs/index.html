PowerShell · IIS · Azure DevOps · Terraform

Ship a zip to IIS.
Roll back if it is not healthy.

A small PowerShell module that deploys a release, checks a health URL, and puts the previous version back on failure. Tested on a real IIS server in CI, not only with mocks.

View the code See the CI runs

One release, five steps

Every release gets its own folder. The site switches over only after the new folder answers 200. If it does not, the old folder is pointed back at and the failed one is deleted.

What CI proves

Four jobs run on every push. The Windows job is the one that matters: it installs IIS and tries to break the deploy.

Real IIS

Deploy, then a bad build

Windows runner installs IIS, deploys v1 and v2, then pushes a build with no health page. The deploy must fail and v2 must keep serving.

Unit tests

Pester on Linux

Switch on healthy, roll back on unhealthy, retry count, missing package, and pruning that never deletes the live folder.

Pipeline

Dev, staging, prod

The Azure DevOps pipeline uses one deploy template three times, each stage depending on the last, each tied to an environment for approvals.

Terraform

Format, validate, scan

Azure and AWS roots are checked with fmt and validate, then scanned with Trivy for high and critical findings.

Use it

Clone, run the tests, then call one function.

# tests (any OS with PowerShell 7)
Install-Module Pester -MinimumVersion 5.5.0 -Scope CurrentUser
Invoke-Pester tests/IisRelease.Tests.ps1

# deploy
Import-Module ./src/IisRelease/IisRelease.psm1
Publish-IisRelease -SiteName MySite -AppPoolName MyPool `
  -PackagePath .\site.zip -ReleaseRoot C:\sites\releases `
  -HealthUrl http://localhost/health.html

What this does not prove

So you do not have to guess.

Not applied

The Terraform has never been applied to a real Azure subscription or AWS account.

Not run

The Azure DevOps pipeline is parsed and checked, not executed. It needs self-hosted Windows agents and environments.

No app code

Function Apps, Service Bus and API Management are provisioned in Terraform only. No application runs on them here.
